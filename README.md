## 💻 Como executar localmente

1. Clone o repositório pelo botão **Code** do GitHub.
2. Abra a pasta do projeto no VS Code.
3. Abra `index.html` no navegador. Se preferir, use a extensão **Live Server**.

O site é estático e não precisa de instalação de dependências para ser visualizado.

## 📁 Arquivos do site

Mantenha o HTML, o CSS, o currículo e as imagens referenciadas no HTML disponíveis no repositório. Se mudar o nome ou a pasta de uma imagem, atualize também o caminho correspondente no `src` do HTML.

```text
.
├── index.html
├── style.css
├── curriculo-jorge.pdf
├── foto_3x4.PNG
├── foto_github.png
└── foto_linkedin.png
```

> Os nomes dos arquivos de imagem precisam corresponder exatamente aos caminhos usados no HTML. Em hospedagens como o Vercel, letras maiúsculas e minúsculas fazem diferença.
